## Visual comparison record

The required viewports are `1440×1000`, `1024×900`, `768×1024`, `390×844`, and `360×844`. Browser captures use Chromium `151.0.7922.34`, DPR 1, `ko-KR`, `Asia/Seoul`, the fixed source time, loaded local font, hidden caret, disabled animation, and zero allowed pixel difference. The 32-case matrix includes full-page gallery/detail, the first-card/detail-aside components, and gallery loading, empty, failure/retry, and corrupt-storage recovery at all five viewports.

Thirteen of 32 comparisons pass the zero-pixel check. The original gallery/detail full-page and component comparisons remain failed. The gallery-empty state is compared to the original source capture: desktop/tablet cases show 27,620 differing pixels, and the two mobile screenshots are 40px shorter. Loading and failure/retry each show 16 differing pixels at 360px in the shared rounded empty-state panel; the remaining three viewports for each state match. Corrupt-storage recovery matches at all five viewports. These pixel results remain unapproved; they are not a similarity score or acceptance.

The three states without supplied source captures use explicit initial screenshot references in [`visual-state-baselines/`](evidence/phase-1/issue31/2026-09-25/visual-state-baselines/). Those references are regression captures, not human-approved UI baselines. They are written only with the explicit `VISUAL_BASELINE_CAPTURE=1` mode; the normal visual command never updates them. The source empty-state reference, prior product baselines, and zero threshold were not changed. Screenshots and per-case metrics are [`visual-comparison.json`](evidence/phase-1/issue31/2026-09-25/visual-comparison.json) and the adjacent PNGs.

The original reference itself was replayed five times in fresh browser contexts. Stable DOM/state metrics were identical for all 130 captures per run and network failures were zero, while exact pixel identity varied from 129 to 131 of 135 images. Across the five runs, six image paths showed a difference at least once; the per-run counts and locations are in [`original-repeat-summary.json`](evidence/phase-1/issue31/2026-09-25/original-repeat-summary.json). The cause remains undetermined. No tolerance, source-baseline update, or visual exception is approved. DomineYH owns the visual-difference review and acceptance.
