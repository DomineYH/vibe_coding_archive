## Visual comparison record

The required viewports are `1440×1000`, `1024×900`, `768×1024`, `390×844`, and `360×844`. Browser captures use Chromium `151.0.7922.34` headless-shell, DPR 1, `ko-KR`, `Asia/Seoul`, the fixed source time, loaded local font, hidden caret, disabled animation, and zero allowed pixel difference. The 32-case matrix includes full-page gallery/detail, the first-card/detail-aside components, and gallery loading, empty, failure/retry, and corrupt-storage recovery at all five viewports.

The first review run passed 13/32 comparisons. Its gallery/detailed-page differences came from a full Chrome versus headless-shell renderer mismatch, an inline layout mismatch on the gallery link, and detail date/icon differences. The empty-state test used a zero-item API fixture and omitted the original gallery and focused-search captures. The visual run now uses the source renderer, matching layout/date/icons, the original 16-item fixture, and the full capture sequence. All 32 comparisons now pass at zero tolerance (0 differing pixels, maximum channel delta 0); no UI-D candidate remains.

The three states without supplied source captures use product-only regression references in [`visual-state-baselines/`](evidence/phase-1/issue31/2026-09-25/visual-state-baselines/). They were re-captured with the source renderer after the prior captures were found to use a different renderer. The original source references and zero threshold were not changed. Screenshots and per-case metrics are [`visual-comparison.json`](evidence/phase-1/issue31/2026-09-25/visual-comparison.json) and the adjacent PNGs.

Five source-only fresh-context replays retain raster differences against the preserved reference (129–131 of 135 captures were pixel-identical); all five failures and their pixel counts remain in [`original-repeat-summary.json`](evidence/phase-1/issue31/2026-09-25/original-repeat-summary.json). The cause investigation is **INCOMPLETE**, so acceptance criterion AC7 is **BLOCKED**. Source hashes, browser/HAR/runtime, recorded state/font metrics, and page/network errors were ruled out. For the 360px empty-gallery capture, the five source-reference counts were 20/18/20/0/89 pixels. A focused rerun mapped the 89-pixel outlier to text pixels in the five subject-filter buttons (16/18/18/18/18) plus one row-container pixel. Exact-sequence captures at 400ms and 800ms after blur both remained 89 pixels from the reference and were 0 pixels apart; focus, scrollbar, caret, animation, and post-blur wait timing were ruled out, but the cause of cross-context glyph raster differences remains unknown. Product-to-source comparison remains 32/32 exact at zero tolerance. No source baseline update, tolerance, or visual exception was needed.
