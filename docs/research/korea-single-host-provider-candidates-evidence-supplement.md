## 1. 조사 배경 및 요구 조건 경계 (Background & Boundaries)

### 1.1 조사 배경
선행 연구([Issue #20](https://github.com/DomineYH/vibe_coding_archive/issues/20) 및 `docs/research/korea-single-host-provider-candidates.md`)에서는 네이버클라우드(NCP)와 카페24(Cafe24) 2개 후보를 대상으로 인프라 조건과 총비용을 검증하였으나, 공식 사이트 다수가 자바스크립트(JS) 기반 동적 컴포넌트 또는 셸 리다이렉트 구조를 사용하여 다수의 핵심 가격·스펙 수치가 `[미확인: JS 렌더링/동적 로드]` 기반의 추정치로 분류되었다.

이에 따라 [Issue #10](https://github.com/DomineYH/vibe_coding_archive/issues/10)의 Q46=A 승인에 의거하여, **기존 두 운영 조합(NCP VM + NHN Cloud 백업, 카페24 VM + NCP Object Storage 백업)과 공통 구성(도메인, 메일, 공지)에 한정**하여 실제 브라우저 동적 렌더링 증거를 확보하고, 공식 공개 문서로 입증되지 않는 항목을 엄격히 분리하여 **미확인 상태와 공식 서면 문의 질문**으로 확정한다.

### 1.2 승인된 검증 원칙 및 용어 정의 (Methodology & Definitions)
1. **렌더링 증거 의무**: 가격 및 스펙은 실제 브라우저 렌더링(Playwright Chromium)을 통해 확인한 값만 인정한다. 정적 HTML 실패, 검색 스니펫, 기억, 선행 보고서의 추정치로 대체하지 않는다.
2. **근거 기록 형식**: 모든 가격·스펙 수치에 대해 **공식 URL, 열람 시각(KST), 선택한 리전/탭/사양 조건, 렌더링된 해당 텍스트**를 기록한다. 여러 셀을 연결한 요약은 '원문'이 아닌 **'표 셀 요약'**으로 구분 표기한다.
3. **기능적 문서 명시(Documented Capability)와 검증된 운영 상태(Verified Operating Fact)의 엄격한 분리**:
   - 공급자 공식 가이드에 특정 설정 기능(예: N일 후 만료 삭제 기능, 국내 리전 선택, 계정 분리 체계)이 문서화되어 있는 것과, 실제 프로비저닝 후 운영 환경에서 보증·수행되는 것은 별개이다.
   - 따라서 콘솔/API 기능 명시는 '문서상 기능 지원 확인'으로 분류하되, **실제 계정 격리, 데이터센터 물리적 위치 실측, 공급자 내부 인프라 복사본의 완전 파기, 복구 모의훈련의 실측 비용은 운영 검증 전까지 '충족 확정'으로 처리하지 않는다.**
4. **비용 표기 및 안분/반올림 규칙**:
   - 본 보고서의 총비용 수치는 **'월 예산 추정치 (Monthly Budget Estimate)'**이며, 확정 청구액이 아니다.
   - **연간 분할 안분**: 도메인 1년 갱신료 22,000원(VAT 포함)의 월 안분액은 정확히 `22,000 ÷ 12 = 1,833.333...원`이며, 세부 표에서는 가독성을 위해 원 단위 반올림(`1,833원`)으로 표기하고 정밀 계산값을 병기한다.
   - **분기 훈련 안분**: 분기 1회 복구 훈련(Drill)에 필요한 추가 비용 시나리오는 3개월로 균등 안분(`÷ 3`)하여 월 상한과 비교한다.
   - **가정치(Allowance) 분리**: 15GB 암호화 백업에 대해 API 호출 및 복원 테스트 여유분을 포함한 `1,100원/월`은 운영 가정치(Allowance)이며, 렌더링으로 확인된 **순수 15GB 저장 단가(NCP 462원, NHN 475.2원)**를 병렬 제시하여 비교한다.
5. **Q33 원칙 불변**: 모든 승인 조건을 입증하지 못하면 **"공개 보류 입력(Holding Input)"**을 유지한다. 미확인은 충족으로 간주하지 않으며, 조건을 임의로 완화하거나 타협하지 않는다.

### 2.4 복구 연습(Recovery Drill)의 월 안분 분석 및 예산 영향

[Issue #21](https://github.com/DomineYH/vibe_coding_archive/issues/21)의 명령과 검증 요청에 따라, 분기 1회 호스트 상실 대비 복구 연습(Drill)에 필요한 추가 비용을 3개월로 균등 안분(`÷ 3`)하여 월 상한(50,000원)과의 정합성을 평가하였다.

1. **카페24 (Cafe24) 분기 복구 연습 시나리오**:
   - **인프라 제약**: 카페24 VPS는 시간제/일제 임시 VM을 지원하지 않으므로, 복구 연습을 위해 별도 VM을 프로비저닝할 경우 **1개월 이용료 33,000원 + 신규 설치비 22,000원 = 55,000원 (VAT 포함)**이 일시 발생함.
   - **월 환산 안분액**: `55,000원 ÷ 3개월 = 18,333.33원 / 월 (VAT 포함)`.
   - **복구 훈련비 포함 시 월 총예산 추정치**:
     - 기본 운영 예산 추정치: 35,933.33원 / 월
     - 복구 훈련 월 안분액: 18,333.33원 / 월
     - **합산 월 예산 추정치**: `35,933.33 + 18,333.33 = 54,266.66원 -> 54,267원 / 월 (VAT 포함)`
   - **결과 판정**: **월 예산 상한(50,000원)을 약 4,267원(+8.5%) 초과하여 [미충족]으로 반전됨.**
2. **네이버클라우드 (NCP) 분기 복구 연습 시나리오**:
   - **시간제 VM 가동**: c2-g2 인스턴스(96원/시) + 공인 IP(5.6원/시) = 101.6원/시 (VAT 별도 = 111.76원/시, VAT 포함).

   - **월 환산 안분액**: `447.04원 ÷ 3개월 = 149.01원 / 월 (VAT 포함)`.
