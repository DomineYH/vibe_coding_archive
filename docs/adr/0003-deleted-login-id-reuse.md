# 삭제된 로그인 아이디는 누구나 즉시 새 회원 가입에 재사용할 수 있다

[#252](https://github.com/DomineYH/vibe_coding_archive/issues/252)의 A안을 채택하여, 관리자 삭제나 최초 승인 대기 만료 삭제가 DB에 반영되면 기존 가입 검증·속도 제한을 통과한 누구나 같은 정규화 로그인 키로 즉시 신규 가입할 수 있다. 현재 존재하는 회원(최초 승인 대기·승인 해제 포함)의 키는 계속 중복 거부한다. 이전 소유자에게 예약하지 않으며 로그인 아이디·별명 일치는 동일인 증명이 아니다. 재가입은 같은 교사라도 새 내부 UUID·일반 회원·최초 승인 대기로 시작하며 이전 승인 이력·앱·세션·복구 권한을 이어받지 않는다. [#9](https://github.com/DomineYH/vibe_coding_archive/issues/9)의 신규 가입 수동 심사와 과거 사람–계정 관계의 본인 확인을 구분하고 자동 승인·과거 자료 복구는 제공하지 않는다.

[#13](https://github.com/DomineYH/vibe_coding_archive/issues/13)의 원자적 삭제와 [#160](https://github.com/DomineYH/vibe_coding_archive/issues/160)·[#161](https://github.com/DomineYH/vibe_coding_archive/issues/161)의 독립 원장·복원 재삭제는 내부 회원 UUID와 앱 ID에 결합되어 로그인 이름 재사용과 독립적이다. 이전 회원이 들어 있는 백업은 이전 회원·앱을 재삭제하고, 새 회원이 포함된 백업은 같은 로그인 아이디라는 이유로 새 회원·앱을 삭제하지 않으며 반복 재적용에도 보존한다. 새 회원이 없는 과거 백업은 복구 시점의 손실이며, 모든 과거 인증 권한은 무효화한다. 원장 확정 대기는 DB 삭제 롤백을 뜻하지 않는다. 관리자 CLI의 현재 키 충돌 거부·일반 회원 자동 승격 금지·기존 관리자만 복구하는 경계도 유지한다.

기간제·영구 재사용 금지나 과거 삭제 아이디 배지는 로그인 이름/해시의 추가 보관과 차단 경로를 요구하므로 도입하지 않는다. 원장은 로그인 아이디를 보관하지 않고, 모든 관련 복사본 만료 확인 후 7일이라는 기존 보관 조건을 유지한다. 현재는 그 증거가 없어 자동 정리하지 않으며 가입 대기 90일·감사 90일·백업 30일을 원장 고정 수명으로 해석하지 않는다. 이는 데이터 최소화 설계 선택이며 법적 준수 판정이 아니다. [PRD](../../PRD/PRD_EduVibe_Archive_v1.0.md)와 [회원 삭제 안내](../development/user-delete.md)·[복원 안내](../operations/restores.md)에 같은 계약을 적용한다.
