# Issue #78 public-read preparation and error boundary — 2026-09-28

## Scope and result

Implements [issue #78](https://github.com/DomineYH/vibe_coding_archive/issues/78), the #77 T01 prefactor. The API frontend starts with authentication explicitly unavailable, so public metadata/list/detail reads do not wait for API auth restore. Canonical `GET /apps` `400 VALIDATION_ERROR` responses map to `ServiceError` and the gallery keeps the entered query visible with an explicit reset. Mock auth and write behavior remain unchanged.

Local code, test, build, reference, and visual checks pass. This does not implement or verify a live backend, database, authentication, writes, admin API, or connection checks. API-mode browser evidence below uses a controlled Playwright route response. Human source-difference/UI-D review and DomineYH's local handover acceptance remain pending.
