## Enforcement and regression

The shared app-create capture path now persists the actual PNG, its individual comparison JSON, the aggregate report and the attachment **before** asserting. Individual JSON survives Playwright worker restarts; a failed worker's aggregate alone is not the complete run inventory. A baseline capture must match the PNG's width and height, report `compared` and have exactly zero different pixels. Null/skipped comparison is never zero. A baseline-free capture remains `product_only`, with null expected dimensions and pixel metrics, and retains its original functional/protected-draft assertions.

`app-create-capture.spec.js` calls this same screenshot/comparison/evidence/verdict path with real PNGs: same-width height mismatch, width mismatch and one changed pixel reject; identical full-page images succeed even when PNG height exceeds viewport height; no-baseline observation succeeds as `product_only`. Each case checks persisted PNG/JSON and attachment. The initial height test failed because the old capture resolved without rejection; the fixed regression passed 5/5. There is no new visual framework, crop, mask, tolerance or baseline regeneration switch. The comparison uses the already-installed, pinned Playwright runner's exported PNG decoder in Node, rather than allocating Image/canvas objects in the product page. Entire raw RGBA channels are compared. Capture follows the installed runner's `expectScreenshot` order: an **exact first frame passes immediately**; only an initial mismatch (or a baseline-free observation) waits within the existing assertion timeout for two byte-identical PNGs, then receives one strict verdict. [Playwright's screenshot API](https://playwright.dev/docs/api/class-pageassertions#page-assertions-to-have-screenshot-1) documents stabilization; the first-frame optimization is in the pinned implementation. `captureStatus` records `expected_match`, `stable` or `unstable`. Last PNG/metrics persist before assertions, including stabilization failure. Persistent width, height or 1px drift still fails; no test retry, timeout, mask or tolerance is changed.
