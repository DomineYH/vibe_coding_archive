# Phase 2 requirement crosswalk — #85

정책 원본: [#77](https://github.com/DomineYH/vibe_coding_archive/issues/77), [#29 §4](https://github.com/DomineYH/vibe_coding_archive/issues/29#issuecomment-5809422519), [#8 §11](https://github.com/DomineYH/vibe_coding_archive/issues/8#issuecomment-5776862857), [#12](https://github.com/DomineYH/vibe_coding_archive/issues/12#issuecomment-5790590858), [#15](https://github.com/DomineYH/vibe_coding_archive/issues/15#issuecomment-5808935379). 명령의 정확한 환경·결과는 [실행 원장](README.md#local-gates)에 있다. PASS는 지정한 로컬 계층/부분만 뜻하며 사람 판정을 뜻하지 않는다. 후속 단계 행은 실제 검사를 미실행으로 기록한다.

캡처 보존: 실제 실행에서 생성·확인한 241장 중 **26장 첨부**, **215장은 로컬에서 생성·확인했으나 커밋하지 않음**. [보존 표](README.md#capture-retention)와 [manifest](capture-inventory.json)의 `committed` 필드로 구분한다. 갤러리·상세는 각 5 viewport 전체를 첨부하며, 나머지 화면은 대표 상태만 남긴다. 결과 JSON의 원래 생성 경로와 전체 viewport 기록은 당시 실행 사실이며 전체 첨부를 뜻하지 않는다. 아래 실행 결과·최초 실패·재검증은 변경되지 않았고, 이번 문서/증거 축소에서 제품 검사는 다시 실행하지 않았다.
