## TDD, failures, and fixes

- Initial targeted unit tests were red for the missing flow mapper/service method and reset/observation-error behavior. The contract → generated type → mapper → Promise service → mock → UI path was added, then the targeted mapping/auth/state/API/OpenAPI tests passed (109/109 across five files).
- The first complete E2E run found three regressions: corrupted-storage recovery expected the old retry label; changing public query keys to be auth-independent stopped public list refresh after mock-store changes; and the cross-tab reset did not refresh the second tab. The recovery locator is now scoped and exact, and storage/reset events re-observe auth before invalidating public metadata/list/detail reads. The four focused cases then passed 4/4.
- The first full visual run passed 62/67 but compared the new header auth-retry state with the old issue #33 corrupt-storage screenshot (2,221 differing pixels per viewport). The five old recovery screenshots are now reported product-only; the original baseline files remain intact. The focused five-case recapture passed, followed by the final full 67/67 visual run.
